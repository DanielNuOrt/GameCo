# GameCo — video game sales analysis

A small descriptive-analysis project based on a historical video-game sales dataset. The exercise considers how sales patterns across markets and platforms could inform the launch and marketing strategy of a fictional games company.

## Objective

Explore historical video-game sales data, summarise patterns in the market and communicate findings in a presentation.

## Techniques

- Data grouping and summarisation
- Descriptive analysis
- Spreadsheet-based analysis
- Visual communication and presentation
